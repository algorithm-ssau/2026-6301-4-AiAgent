# Alcohol Censor

Групповой проект по теме «ИИ-агент для цензуры», обучающиеся группы 6301-020302D.

Программа в реальном времени находит алкоголь на экране через нейросеть и закрывает его чёрными прямоугольниками поверх изображения. Работает на Windows и Linux.

## Запуск

### Готовый EXE

Скачайте установщик из раздела [Releases](../../releases) и запустите его. После установки откройте `AlcoholCensor.exe`. Обученная модель автоматически размещается в `C:\Users\<username>\AppData`.

### Из исходников

```bash
pip install -r requirements.txt
python main.py
```

Откроется окно управления — выберите модель, выставьте порог уверенности и нажмите «Включить цензуру».

Файл модели `Models/best.onnx` должен быть в папке проекта. Если его нет — запустите обучение (см. ниже).

### Linux

```bash
sudo pacman -S xdg-desktop-portal pipewire gstreamer gst-plugin-pipewire \
               gst-plugins-base python-dbus python-gobject gtk-layer-shell
python main.py
```

### AMD GPU

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/rocm7.1
```

Видеокарта определится автоматически.

## Тесты

```bash
python -m pytest Tests/
python -m pytest Tests/test_tracker.py
```

`Tests/test_detector.py` требует наличия `Models/best.onnx`, `Tests/test_tracker.py` — нет.

## Обучение модели

```bash
pip install -r requirements-train.txt
python train.py
```

Скачивает датасет с Roboflow (7332 изображений, 5 классов алкоголя), обучает модель и предлагает сохранить результат в `Models/best.onnx`.

## Архитектура

Общая схема работы:

```
Захват экрана → YOLO → Сглаживание треков → Оверлей
```

Программа работает в четырёх потоках: захват кадров, детекция и трекинг, статистика FPS, отрисовка оверлея. Скорость — около 20 FPS на CPU.

### Модули

**`Core/capture.py`** — захват экрана. На Windows и Linux использует `mss`, на Wayland бросает ошибку (не реализовано).

**`Core/detector.py`** — детекция через YOLO. Поддерживает `.pt` и `.onnx` модели, автоматически выбирает GPU если доступен (NVIDIA, AMD, Intel).

**`Core/tracker.py`** — сглаживание координат между кадрами через EMA-фильтр, чтобы прямоугольники не дёргались.

**`Core/utils.py`** — счётчик FPS.

**`Overlay/windows/overlay_win.py`** — прозрачное окно поверх рабочего стола на Windows, рисует чёрные прямоугольники.

**`Overlay/linux/overlay_lin.py`** — то же самое для Linux на GTK3.

**`gui.py`** — интерфейс управления на tkinter.

**`main.py`** — точка входа, защита от двойного запуска.

**`train.py`** — скрипт обучения модели.
